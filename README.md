# elemintro | Periodic Table Study Website

elemintro is a website for students to make studying the periodic table interactive. 

## Periodic Table

The [Periodic Table] screen is designed to make studying the elements simple. Each element can be hidden by clicking on the element, or alternatively, clicking the Hide All button, letting the user test their memory against the element's symbol.

## Grid Game

The [Grid Game] screen gives you the name of an element with six clickable element symbols. The goal is to choose the correct symbol for the given element. Do it on the first try to increase your answer streak.
